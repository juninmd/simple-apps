# Contributing to Voice Vault

We love your input! We want to make contributing to Voice Vault as easy and transparent as possible.

## Pull Requests

1. Fork the repo and create your branch from `master`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes (`pnpm test`).
4. Make sure your code lints.
5. Format your code (e.g., using Prettier).

## Issues

We use GitHub issues to track public bugs. Report a bug by opening a new issue; it's that easy!
