# Reaction Trainer

A simple React Native app built with Expo to test and train your reaction time.

## Features

- Measure reaction time in milliseconds.
- Visual cues for readiness and action.
- Feedback for early taps.

## Getting Started

### Prerequisites

- Node.js
- pnpm

### Installation

1. Clone the repository.
2. Install dependencies:

```bash
pnpm install
```

### Running the App

```bash
pnpm start
```

This will start the Expo development server. You can run the app on:

- Android Emulator
- iOS Simulator
- Your physical device using the Expo Go app.

## Project Structure

- `App.tsx`: Main application component.
- `app.json`: Expo configuration.
