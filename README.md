## Sobre

Simple Apps é um monorepositório que reúne 14 aplicativos móveis pequenos e funcionais, cada um focado em uma utilidade específica. Ideal para aprendizado, prototipagem rápida e reuso de componentes.

## Apps Inclusos

| App | Descrição |
|-----|-----------|
| Color Palette | Gerador e explorador de paletas de cores |
| Daily Affirmations | Afirmações diárias positivas |
| Decision Roulette | Roleta para decisões aleatórias |
| Hydration Tracker | Monitoramento de ingestão de água |
| Morse Code Flasher | Conversor e piscador de código Morse |
| Pomodoro Focus | Timer Pomodoro para foco |
| Reaction Trainer | Treinador de tempo de reação |
| Simple BMI | Calculadora de IMC |
| Strobe Light | Efeito de luz estroboscópica |
| Tally Counter | Contador simples |
| Tip Splitter | Divisor de conta e gorjeta |
| Unit Converter Pro | Conversor de unidades |
| Voice Vault | Gravador e armazenamento de voz |
| Zen Breather | Exercício guiado de respiração |

## Stack

| Camada | Tecnologia |
|--------|-----------|
| Framework | Expo 54 |
| UI | React Native 0.81 |
| Linguagem | TypeScript 5.9 |
| Testes | Jest + Jest Expo |

## Instalação

```bash
git clone https://github.com/juninmd/simple-apps.git
cd simple-apps
npm install
```

## Uso

```bash
# Iniciar cada app individualmente
cd app-color-palette
npx expo start

# Testes
npm test
```

Cada subdiretório `app-*` é um aplicativo independente que pode ser executado separadamente.
