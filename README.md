# Color Palette Generator

A simple React Native application to generate and view color palettes. Built with Expo.

## Features

- Adjust Red, Green, and Blue values via sliders.
- View the resulting color and HEX code.
- Copy HEX code to clipboard.

## Getting Started

### Prerequisites

- Node.js
- npm or pnpm
- Expo Go app on your mobile device (optional, for physical device testing)

### Installation

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the App

Start the Expo development server:

```bash
npm start
```

Press `a` for Android (requires Android Studio/Emulator), `i` for iOS (requires Xcode/Simulator on macOS), or scan the QR code with Expo Go.

## Testing

Run unit tests:

```bash
npm test
```
