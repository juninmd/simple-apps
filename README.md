# Decision Roulette 🎯

A simple, fun React Native application to help you make decisions! Spin the wheel and let fate decide.

## Features
- 🎡 Animated spinning wheel
- 🎲 Random result generation
- 📱 Cross-platform support (Android, iOS) via Expo

## Getting Started

### Prerequisites
- Node.js
- [pnpm](https://pnpm.io/)
- [Expo Go](https://expo.dev/client) app on your mobile device (or an emulator)

### Installation
1.  Clone the repository:
    ```bash
    git clone https://github.com/[YOUR_USERNAME]/[YOUR_REPO].git
    ```
2.  Install dependencies:
    ```bash
    pnpm install
    ```

### Running the App
Start the Expo development server:
```bash
pnpm start
```
Scan the QR code with Expo Go to run on your device.

## Scripts
- `pnpm start`: Start Expo
- `pnpm android`: Run on Android emulator
- `pnpm ios`: Run on iOS simulator
- `pnpm test`: Run tests
