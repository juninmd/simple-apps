# Agent Instructions & Roadmap

This file guides the behavior of AI agents working on this repo.

## Guidelines
- Use `npm` for dependency management (as `package-lock.json` exists).
- Ensure 100% test coverage for new or modified logic.
- Follow the '100-line' logic rule where applicable.
- Update `GEMINI.md` with new learnings.

## Future Roadmap
1. **Theming Support**: Add support for dark/light mode switching beyond just the container background.
2. **Save Palettes**: Allow users to save their favorite colors to a local list (AsyncStorage).
3. **Color Harmony**: Add features to generate complementary, analogous, or triadic colors based on the current selection.
