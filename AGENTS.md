# AGENTS.md

## Repository Overview
This repository contains a Reaction Trainer app built with React Native and Expo.

## Instructions for Agents
- **Scope**: Changes should be focused and verified.
- **Tools**: Use `pnpm` for dependency management.
- **Testing**: Ensure 100% test coverage for new or modified code. Run `pnpm test` before submitting.
- **Linting**: Follow standard linting rules (ESLint + Prettier). Run `pnpm run lint` and `pnpm run format` before submitting.
- **Environment**: Expo environment.
- **CI/CD**: CI checks run on push/pull_request to master. Ensure they pass.
